# v0.1.0 预览版

这是 CPEditor-Native 的首个公开预览版，发布标签为 `v0.1.0`，GitHub Release 标记为 Pre-release。下载入口为 [v0.1.0](https://github.com/A-BenLi06/CPeditor-Native/releases/tag/v0.1.0)。

本轮提供 macOS Apple Silicon 原生应用 ZIP 和 `SHA256SUMS.txt`。Windows 源码包含在标签内，但不提供尚未完成目标机验证的安装包。发布说明以英文面向下载用户，介绍原生工作区、GNU G++、常显样例面板、编辑辅助与结果过期识别，并明确预览边界。

## 构建与检查

- 应用版本为 0.1.0，构建号为 1。共享 Core 使用 CMake Release，Swift 应用使用 SwiftPM release，实际构建主机为 macOS 27.0.1 arm64，Xcode 27.2 / SDK 27.2。
- 优化构建通过 17 项 Core 测试，以及 21 项编辑规则、双编辑器原生撤销／输入法、G++ 编译运行、判题结果专项测试。代码基线 `ac67d41` 的 [macOS CI](https://github.com/A-BenLi06/CPeditor-Native/actions/runs/44576315420) 通过完整 101 项 Swift 测试和 17 项 Core 测试。
- ZIP 附带 GPL、第三方许可证、固定 SwiftPM 依赖记录、源码地址及本次使用的构建脚本。核对全部 SwiftPM checkout 与锁定提交一致；应用只链接系统动态库。
- 核对 Mach-O arm64、最低系统 26.0 和 SDK 27.2，检查 Info.plist、临时签名和解压后签名。解压应用通过 LaunchServices 启动检查，加载独立恢复文件、保存一份文档记录并正常退出。
- 包名为 `CPEditor-Native-v0.1.0-macos-arm64.zip`，最终字节校验值以同一 Release 附带的 `SHA256SUMS.txt` 为准。工作日志和构建回执保存在本地 `out/releases/v0.1.0/`。

## 已知边界

应用采用 ad-hoc 临时签名，未完成 Developer ID 签名和公证，下载后可能被系统阻止。macOS 26 最低系统与 Intel 尚未实测；Windows x64 Debug／Release 的 CI 成功不代表 Windows 10 桌面体验验收。C++ 默认要求单独安装 GNU G++，例如 Homebrew GCC；Apple 的 `/usr/bin/g++` 别名不满足要求。语义补全与整应用性能验证仍待完成。
