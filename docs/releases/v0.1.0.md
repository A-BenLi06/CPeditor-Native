## 版本迭代规则

自 `v0.1.0` 起，后续版本按 **`0.1.x` 补丁号持续递增**（`v0.1.0` → `v0.1.1` → `v0.1.2`…）。未经用户明确指示，不主动提升前两位版本号。

## 已知边界

- macOS 产物采用 ad-hoc 临时签名，未经过 Developer ID 签名与 Apple 公证，下载解压后首次运行可能触发系统拦截。
- 声明最低系统版本为 macOS 26.0，当前仅在 macOS 27.0.1 Apple Silicon（arm64）验证；macOS 26 最低系统实机与 Intel 架构尚未验证。
- C++ 默认工具链需要单独安装真正的 GNU G++（例如 `brew install gcc`）；Apple 自带 `/usr/bin/g++` 为 Clang 别名，不能作为 GNU G++ 使用。
- Windows 版本当前仅包含源码与 Windows Server 2022 编译 CI 记录，Windows 10 22H2 真机桌面体验（IME、DPI、UU 远程、虚拟桌面）仍待验收，暂不提供安装包。
- 语义 C++ 补全（clangd/LSP）、正式发布签名与完整整应用性能基线测试仍待后续版本完善。
