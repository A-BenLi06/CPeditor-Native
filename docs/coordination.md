# 实施协作协议

- 根 agent 负责共享接口、构建入口、文档状态、walkthrough 和 Git 提交。
- 子 agent 仅编辑领取目录；共享头文件修改先与根 agent 协调，避免并行覆盖。
- 每项工作在 claims 中登记文件所有权；完成后记录构建/测试证据，释放所有权。
- 子任务不各自提交或改写流水；根 agent 将经过验证的完整变更集统一记录并提交。
- Windows 与 macOS 的验证证据分别记录，不能用跨平台源码检查代替目标系统运行。
- M0 硬件/编辑器验收仍是生产选型条件。可移植领域层与进程接口可独立推进；未经目标主机验证的编辑器不会被标记为生产就绪。
