# v0.1.1 预览版

这是 CPEditor-Native 的第二次公开预览发布，发布标签为 `v0.1.1`，GitHub Release 标记为 **Pre-release**。下载入口为 [v0.1.1](https://github.com/A-BenLi06/CPeditor-Native/releases/tag/v0.1.1)。

本版本聚焦 **macOS 原生窗口界面与 Xcode 风格层级重构**、**编译错误卡片渲染缺陷修复**，同时合入 `v0.1.0` 之后在 **`main` 主干完成的 Windows WinUI 3 产品化工作**（源码已随 `v0.1.1` 标签发布，本轮暂不附带 Windows 预编译安装包）。

## 发布产物与校验

- 应用版本：`0.1.1`（macOS `CFBundleVersion` 为 `2`；Windows 清单为 `0.1.1.0`；CMake `PROJECT_VERSION` 为 `0.1.1`）
- 压缩包：`CPEditor-Native-v0.1.1-macos-arm64.zip`（`2,572,961` 字节）
- SHA-256 校验文件：`SHA256SUMS.txt`
- 校验值：`83eb8ff9bf2a718c478136bafced6721685a16117d9e107147b303ed6b256e80`

压缩包内置 `CPEditorNative.app`、`LICENSE`、`THIRD_PARTY_NOTICES.md`、`Licenses/`（含 SwiftPM 直接／传递依赖与 Core 第三方声明）、`SwiftPM-Package.resolved.json` 与 `SOURCE.md`。本地构建日志与回执归档在被忽略的 `out/releases/v0.1.1/` 目录。

## 主要变更（相比 v0.1.0）

- **macOS 原生 Liquid Glass 胶囊标签栏与拖动排序**：
  - 参照 Xcode 多标签风格重构为等宽胶囊，在 macOS 26/27 采用系统原生 `GlassEffectContainer` 与 `.glassEffect(.regular.interactive(), in: Capsule(style: .continuous))` 选中胶囊材质，置于悬浮全圆角外框轨道内。
  - 标签栏严格限定于左侧编辑器区域，不越过右侧测试栏；展开或调整 Inspector 宽度时左侧空间自然挤压适配。
  - 支持水平拖动调整标签顺序并持久化到工作区恢复文件，保持编辑器挂载实例与 `UndoManager` 撤销历史不变。
- **macOS Xcode 风格全高原生 Inspector 与排布精简**：
  - 采用 SwiftUI 原生 `.inspector(isPresented:)` 替代自绘分栏分割条，右侧测试栏与分隔线贯穿标题栏高度；统一底部极简状态栏与单层 Inspector 头部。
  - 右上角布局按钮简化为单个 `sidebar.trailing` Inspector 切换按钮（分栏展开时停靠 Inspector 顶栏最右端，保留 `⌃⌘1` / `⌃⌘2` / `⌃⌘3` / `⇧⌘Y` 快捷键）。
  - 调整默认 Inspector 宽度（`510 pt` / 最大 `700 pt`），分栏模式改为等宽平铺 `Compile` / `Run` / `Compile & Run` 操作栏 + `Checker:` 属性对照行；将 `Compiler Output`、`TestCase` 与历史移除结果统一为 `10 pt` 圆角卡片搭配左端状态色条。
- **修复 CE 编译错误卡片导致 `.inspector` 空白渲染缺陷**：
  - 排查并移除 `CompilerOutputBanner` 中导致 `.inspector` 整窗主体空白塌陷的 `DisclosureGroup`，改用自定义可折叠卡片并将 `CompilerOutputBanner` 移入右侧 `ScrollView` 内，同步补充离屏渲染像素采样回归测试 `compileErrorInspectorRendersVisibleLeftAndRightContent`。
- **Windows WinUI 3 主干合入（`0e1ba8b`、`b4322f2`）**：
  - 接入 VS 2026 工具链探测并完善 WinUI 3 多标签编辑、运行编译器自动发现、Visual/JSON 配置、Output 先行三栏测试对照、外部 Checker、Companion 收件箱筛选与原生设置页，并在 Windows 10 22H2 专业工作站完成过 Debug 部署激活与 Release x64 构建验证（详见 [实施状态与证据](../status.md)）。

## 构建、测试与实机截图核验

- **本次发布执行主机**：macOS 27.0.1（26A434）arm64，Xcode 27.2（27B52）/ SDK 27.2，Swift 6.4.2，Apple Clang 21，CMake 4.4.3；**本次未在 Windows 主机执行新验证或打包**。
- **Release 实机测试**：在 `CPN_REQUIRE_GNU_CPP=1` 条件下，Release Core CTest **17/17** 全部通过（`4.51s`），Release SwiftPM 全量测试 **18 个套件 114/114** 全部通过（`15.569s`，含真机 Homebrew `g++-15` 编译运行 `bits/stdc++.h`、标签重排持久化和 CE 渲染防空白像素测试）。
- **二进制与签名检查**：`script/verify_macos_build.py` 核对 15 个 Core Mach-O 对象与最终可执行文件均为 `arm64`、`minos 26.0`、`sdk 27.2`；`otool -L` 确认仅链接系统动态库；`plutil -lint`、`codesign --verify --strict`（打包前与解压后）全部通过，验证 `CFBundleShortVersionString == 0.1.1`、`CFBundleVersion == 2`。
- **真机运行与截图核验**：在隔离恢复工作区启动解压后的 `v0.1.1` `CPEditorNative.app`，使用真机 `g++-15` 完成浅色／深色分栏运行（`AC` 23 ms / `WA` 7 ms）、`⌃⌘3` 仅测试输出视图、Companion 收件箱、Settings 工具链弹窗与深色模式真实编译错误诊断（`CE` 506 ms / `339 B`）共 **6 张新版真机截图**并已逐张目视核验，更新至 [docs/screenshots/](../screenshots/)。

## 版本迭代规则

按照仓库约定，版本号继续按 **`0.1.x` 补丁号持续递增**（`v0.1.0` → `v0.1.1` → `v0.1.2`…）。未经用户明确指示，不提升前两位版本号。

## 已知边界

- macOS 产物采用 ad-hoc 临时签名，未经过 Developer ID 签名与 Apple 公证，下载解压后首次运行可能触发 Gatekeeper 拦截。
- 声明最低系统版本为 macOS 26.0，当前仅在 macOS 27.0.1 Apple Silicon（arm64）验证；macOS 26 最低系统实机与 Intel 架构尚未验证。
- C++ 默认工具链需要单独安装真正的 GNU G++（例如 `brew install gcc`）；Apple 自带 `/usr/bin/g++` 为 Clang 别名，不会作为 GNU G++ 使用。
- Windows 版本源码随 `v0.1.1` 标签合入（版本清单已同步至 `0.1.1.0`），但桌面交互、中文 IME、高 DPI 与 UU 远程仍待目标机交互桌面验收，本预览版暂不附带 Windows 安装包。
- 语义 C++ 补全（clangd/LSP）、正式发布签名与完整整应用性能基线测试仍待后续版本完善。
